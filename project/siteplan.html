Website Planning Document

Brick Explorer

Site Name

Brick Explorer

This name was selected because it represents exploring the world of Lego, including different themes, collecting, building techniques, and beginner information. The website is intended to be an easy guide for Lego fans of all experience levels.

Optional possible domain: brickexplorer.com

Site Purpose

Brick Explorer is mainly a informational website designed to introduce visitors to the Lego hobby. It provides information about popular Lego themes, collecting tips, beginner advice, and showcases impressive Lego builds to help visitors discover new interests within the Lego community.

Scenarios

  • Which Lego theme would be the best choice for a beginner?
  • What are the some of the most popular Lego themes available today?
  • What is the best I can start collecting without spending too much money?
